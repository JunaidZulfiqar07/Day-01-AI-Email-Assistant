# 🚀 AI Email Assistant using n8n

An AI-powered email automation workflow built with **n8n**, **OpenAI/Gemini**, **Gmail**, and **Google Sheets**.

---

## 📌 Project Overview

This project automatically generates professional business emails based on user input using AI.

After generating the email, it:

- Creates a professional subject line
- Sends the email through Gmail
- Logs activity into Google Sheets

---

## ✨ Features

- 🤖 AI-generated professional emails
- 📧 Automatic Gmail integration
- 📊 Google Sheets logging
- 🧠 Structured AI output
- 🎨 Multiple email tones
- ⚡ Built with n8n automation

---

## 🛠 Tech Stack

- n8n
- OpenAI / Google Gemini
- Gmail API
- Google Sheets
- AI Agent
